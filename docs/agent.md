# Плата и админ-панель

[← к оглавлению](../README.md)

Агент — программа на C# под .NET nanoFramework 1.18 для платы ESP32-S3 (цель прошивки `ESP32_S3_OCTAL`).

## Два режима

**Режим настройки.** Плата поднимает свою сеть Wi-Fi `MyPrintAgent` (пароль `printagent`); панель открывается с телефона по адресу `http://192.168.4.1/`. Режим включается, если:

- настроек ещё нет;
- к сохранённой сети Wi-Fi не удалось подключиться за 60 секунд;
- кнопку BOOT держали нажатой 3 секунды;
- программа три раза подряд упала при запуске.

**Рабочий режим.** Плата подключена к роутеру, опрашивает бэкенд и печатает. Панель доступна по адресу платы в сети и по имени `http://myprintagent.local/`.

Светодиод мигает медленно в рабочем режиме и быстро в режиме настройки.

## Админ-панель

Одна страница, которую отдаёт сама плата; свёрстана под телефон.

| Раздел | Что в нём |
|---|---|
| Состояние | Режим, Wi-Fi, связь с бэкендом, состояние принтера, последнее задание, время платы |
| ID устройства | GUID, по которому бэкенд адресует задания; кнопки «Скопировать» и «Создать новый» |
| Принтер | Название, IP-адрес, порт, ширина строки, ID принтера; «Проверить связь», «Тестовая печать» |
| Поиск принтеров в сети | Перебор диапазона адресов по порту принтера, найденный адрес выбирается кнопкой |
| Сеть Wi-Fi | Имя и пароль сети |
| Бэкенд | Адрес и период опроса |

Изменения применяются кнопкой «Сохранить и перезагрузить».

**ID принтера** создаёт сама плата. Он остаётся прежним, пока не меняются IP-адрес и порт принтера; при смене адреса или порта создаётся новый. Название принтера — для людей, на печать оно не влияет.

**Тестовая печать** печатает линейку `1234567890…` во всю заданную ширину строки: по ней видно, верно ли выбрана ширина.

**Поиск принтеров** проверяет один адрес примерно за полторы секунды: 254 адреса — около 7 минут. Печать во время поиска идёт с задержкой до 2 секунд.

## Настройки

Хранятся файлом JSON во внутренней памяти платы: ID устройства, имя и пароль Wi-Fi, адрес бэкенда, период опроса, название, ID, IP-адрес и порт принтера, ширина строки.

Значения для новой платы — в `firmware/PrintAgent/Defaults.cs`, имя и пароль Wi-Fi — в `Secrets.cs` (в Git не попадает).

## Поведение при сбоях

| Что случилось | Что делает плата |
|---|---|
| Принтер выключен, нет бумаги, открыта крышка | Задание сразу получает `Failed` с причиной; очередь не копится |
| Пропало питание во время печати | После включения сообщает `REBOOT_DURING_PRINT` и чек заново не печатает |
| Бэкенд недоступен | Ждёт и повторяет; итог напечатанного чека доставит, когда связь вернётся |
| Бэкенд трижды подряд отверг итог с кодом 400 | Перестаёт повторять этот итог и берёт следующее задание |
| Задание не разобралось | `BAD_JOB` |

Журнал печати ведётся в двух файлах: отметка «начато» и итог. Запись итога не стирает отметку, поэтому обрыв питания посреди записи не оставляет плату без сведений о напечатанном чеке.

## Время

После подключения к Wi-Fi плата до 10 секунд ждёт, пока её часы сверятся с интернетом, и продолжает работу в любом случае. Если часы не сверены, время на чек берётся из задания — его туда кладёт бэкенд.

## Особенность платы: USB

Любая программа на компьютере, открывшая COM-порт платы, перезагружает её: так устроен встроенный USB у ESP32-S3. При питании от блока питания без компьютера этого нет.
